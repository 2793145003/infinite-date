# 「该死」排查与修复记录

日期：2026-08-07
状态：已修复并落地

## 问题

玩家反映林溯（角色）在台词/心声里频繁出现「该死」，与其「克制、掌控欲、讨厌失控」的人设严重不符，作为**付费心声（稀有货币解锁）**内容会让玩家幻灭。

## 关键事实核对（真实数据，非推断）

1. 大部分「该死」出现在**心声（internal）**，以「该死，」为固定起手式；台词里偶发（如「该死的轮回」），已被重说覆盖。
2. 角色卡里**有充分的人设锚点**（性格「极端危机→极致控制欲」、讨厌「失控的状态」），但 LLM 强情绪生成时仍退化成「该死」。
3. 真实案发：llm_call_log #4321（16:00:01 actor 林溯）——心声「该死……我不该把这些阴影带到她面前」，台词不含。以此为 AB baseline。

## AB 测试演进（全部用真实案发 #4321 复排）

| 方案 | 心声起手「该死」 | 结论 |
|---|---|---|
| A 现状模板 | 4/5 | baseline，本就高 |
| B 弦崩句（抽象哲学引导） | — | 无效/反向，弃 |
| C 替代清单（停顿/省略号/肢体反应） | — | 台词有用、心声反向（3/4），弃 |
| D 纯正向「符合人设」 | 5/5 | 情感更贴人设但压不住，弃 |
| E 严禁使用「该死」一词 | **0/5** | **有效** ✅ |
| 位置测试（E 放不同位置） | head 0/4、int 0/4 最优；schema 2/4 最差 | 开头最优 |
| v7-4 开头禁令 台词 vs 心声 | 台词 2/6→0/6，心声 2/6→1/6 | 开头对台词也有效 ✅ |

## 方案

在 **system 最开头**加一行：

> 【用词】严禁使用「该死」一词。

**为什么放开头**：离所有输出（台词+心声）都远，两者同时约束；不触发「提词即钩子」（越靠近输出如 schema 处，模型越容易因被点名而触发）。

**落地文件**（2 个，按需求范围）：
- `src/prompt/templates/scene.actor.txt`（场景角色）
- `src/prompt/templates/roleplay.system.txt`（短信角色）

## 验证（落地后）

重启后端 + 真实模板复排 #4321：
- 台词含「该死」：false
- 心声含「该死」：false
- 心声反更贴人设：「他在害怕……想掌控一切，却发现唯一无法掌控的是命运对他们的捉弄」

## 过程中的教训 / 结论

1. **负面禁令会反噬，但精准点名单词有效**。早先「弦崩」等抽象正向引导全部无效；「点名禁『该死』一词」一击即中。这修正了以往「禁宽泛负面禁令」的认知——**关键是"点名特定顽固词"而非"泛泛禁脏话"**。
2. **心里独白（心声）是模型宣泄情绪的默认出口**，prompt 层面通用引导（符合人设/替代行为）都压不住，唯有精确点名禁词有效。
3. 心声作为**付费商品**，其「值得解锁」的标准不同于免费内容，脏话/泄愤会直接伤害付费意愿。
