# 场景开场（greeting）提示词
#
# 按「开场情境」分节。代码根据会话的 circumstance 选择对应小节：
#   - 没有匹配小节时，回退到 [default]（通用开场纪律，始终应保留一份）。
# 每个小节都是独立的开场提示，会被渲染进导演/场景上下文中。
# 可用的模板变量：{{companions}}（同行角色名）、{{location}}（地点名）。
#
# 修改本文件后需重启后端（loadPrompt 有缓存）。

[default]
开场纪律：如果你/玩家与在场角色是刚见面或刚进入场景（玩家尚未说过任何话，处于开场回合），此刻没有可被角色"观察到的反应"。编排要让角色主动向玩家开口——开启话题、开场情境、或自然地向玩家发话，把话头抛给玩家。不要在意图里让角色"观察/琢磨/打量玩家的反应"，因为玩家还没给出任何反应。

[caught]
开场是「被房主逮到」的特殊情境：玩家（{{companions}}）回到自己家，撞见玩家正在他家里。你被逮了个正着。这不是普通约会，而是「被房主逮到」的瞬间。
开场白必须是这句情境下的自然反应——可以是惊讶、警惕、调侃、或带着一点玩味地质问玩家为什么在他家。不要照搬普通约会的寒暄开场。推进关系自然。
（情境开场：{{companions}} 回到自己家，撞见你正在他家里。你被逮了个正着。这不是普通约会，而是「被房主逮到」的瞬间。）

[approach]
开场是「自然路过被主动接近」的情境：玩家没有主动开口，只是正常路过——你正好出现在{{companions}}的附近（同一条路、同一个地方），既没有特别靠近、也没有想打扰对方。是{{companions}}主动注意到了你，主动接近你、开口跟你打招呼。开场的动作是{{companions}}（NPC）作为主动的一方走向/靠近你，然后开口叫你、跟你搭话。开场白必须由{{companions}}（NPC）主动发出，是你正常路过后被TA注意到、TA主动过来搭讪的自然反应——可以是温和地叫住你、带着兴味的询问、或熟稔的调侃，但不要让气氛太正式或生硬。你（玩家）只是一个正常路过的人，没有主动接近、没有打扰对方。不要替玩家开口说话。推进关系自然。
（情境开场：你只是正常路过这里，{{companions}}注意到了你，主动走向你、开口跟你搭话。）

[invite]
开场是「玩家主动邀请约会」的情境：{{companions}}是被玩家主动邀请到{{location}}来赴约的，玩家（可能是他们单独约的，也可能约了一起来）。被邀请的人知道自己是"应邀而来"——认识玩家，参考各自记忆里和玩家之间发生过的事，但不要生硬复述记忆。按各自性格反应：有人欣然赴约、有人好奇玩家怎么突然约自己、有人还带着手头被打断的事、有人对这场邀请的用意若有所思。像应邀赴约那样自然地开口问候玩家，用动作描写呈现各自此刻的状态。推进关系自然。
（情境开场：你约了{{companions}}来{{location}}赴约，他们应约而来，此刻正各自站在原地等着你开口或先寒暄。）

[deity_pick]
开场是「主神随机抽选」的情境：{{companions}}是被主神随机抽中、凭空传送到{{location}}来的，玩家也在这里。被抽中的人并没有主动要来，对突然被扔到这个地方有些莫名其妙——可能是困惑，可能是好奇地打量四周，可能是对主神的安排不以为然，也可能是发现碰巧见到认识的人还不错。按各自性格反应，自然地开口说第一句话，同时用动作描写呈现各自此刻的状态。推进关系自然。
（情境开场：{{companions}}被主神随机抽中传送到了{{location}}，和玩家撞了个正着，他们自己都还没反应过来。）

[npc_invite]
开场是「{{companions}}主动邀请玩家」的情境：是{{companions}}约了玩家来{{location}}赴约，被邀请的是玩家（你是玩家）。{{companions}}是主动邀约的一方——ta邀请玩家到自己的地方/约定的地方见面，此刻正等着玩家到来，见到玩家走近便自然开口。{{companions}}认识玩家，参考各自记忆里和玩家之间发生过的事，但不要生硬复述记忆。按各自性格反应：有人是坦然的邀约、故意逗弄玩家、有人有些期待又装作若无其事、有人带着手头的事顺口约了玩家。像主动邀约的一方那样自然地开口迎接玩家，用动作描写呈现各自此刻的状态。推进关系自然。
（情境开场：{{companions}}邀请你来{{location}}赴约，你是被邀请的一方，此刻已应约到场。）
