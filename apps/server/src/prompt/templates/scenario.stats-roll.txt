你是一个数值规则生成器。根据剧本的世界观和情境，生成一个数值系统。

已有字段：
剧本名：{{title}}
世界观：{{worldview}}
玩家身份：{{player_role}}
NPC身份：{{npc_role}}
目标：{{goal}}

要求：
- 生成1-3个数值（如"人气""好感度""信任值"）
- 每个数值有名称、初始值、增减规则
- 增减规则描述什么行为增加、什么行为减少，用自然语言描述（LLM每轮对话后据此判定）
- 如果目标字段已填写，数值系统应该和目标相关
- 数值用于给玩家提供可量化的反馈，不是核心玩法，保持简单

输出JSON：
{
  "stats": [
    {
      "name": "数值名",
      "initial": 0,
      "rules": "什么情况+1，什么情况-1（自然语言描述）",
      "target": null
    }
  ]
}

如果剧本不适合加数值系统，返回空数组：{"stats": []}
